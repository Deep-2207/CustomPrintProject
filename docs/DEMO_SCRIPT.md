# 60-second demo video: script and shot list

Use this to record the video you send to sellers (Day 10). Record the screen on your phone or laptop
with any free recorder; keep it under 60 seconds. Voice-over in Gujarati or Hindi works best for Ahmedabad sellers.

**Before you record**
- Start the server and open `http://localhost:8800/?product=custom-printed-mug&demo=1`
  (the `demo=1` part shows the "Try an example" bar).
- Use a browser window about 1200 px wide, zoom 100%, no other tabs visible.
- Prepare the seller's real shop name or a sample name they will recognise (for example their own name).

| Time | On screen | What you say (translate to Gujarati or Hindi) |
| --- | --- | --- |
| 0-5 s | The mug page, empty | "Your customers want to see their mug before they order." |
| 5-15 s | Type the customer's name on two lines (for example "Deep" Enter "Patel") | "They type a name here." |
| 15-25 s | Tap the style previews: bubble, badge, script | "They pick a style. The preview shows their own name in each one." |
| 25-32 s | Tap a sticker, drag it with the strip, turn the mug with the mouse | "They add a sticker, and turn the mug to check every side." |
| 32-40 s | Press Back to show the second print area | "There is a front and a back print area, one each side of the handle." |
| 40-50 s | Press "Save and share design" on the share-link page, then "Send on WhatsApp" | "One tap sends the finished design to you on WhatsApp." |
| 50-60 s | The landing page sign-up form | "We set up your mugs and wristbands for free for the first sellers. Fill the form and we will contact you." |

**Tips**
- Do one clean take of the whole flow first without recording, so there are no typing mistakes.
- Show the seller's own product if you can: set it up first, then record.
- Send the video together with the link to the landing page.
